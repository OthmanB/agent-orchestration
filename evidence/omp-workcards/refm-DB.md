## Mechanism rule (D-B). Verified on disk 2026-11-10
Fields: `TickRecord.{scored,skip_reason,p_raw}`, `MetricTick.{reason,model_t0,ess}` (`chain.py:249-283`), reasons `"model not built"`/`"model stale"` (`chain.py:286-287`; no model ⇒ metric unscored; pod skipped only if cpu (the sole mandatory metric) is unscored or no metric has ring fill ≥3 of 4), `ReferenceRun.{model_t0,ess}` (`provider.py`), `CycleReport.reason ∈ built|few_blocks|ess_gate` via `StlLiteProvider.run(on_cycle=)` (`stl_lite.py:171,340`, `harness/ess.py:37-79`); dt=1800 s = 6 ticks; `truth.quiet_mask` (anomaly span incl. guard; regimes/gaps stay quiet).
- `no_model[k]` = `k+1 ≥ scoring.warmup_tick_end_offset` ∧ ∃ served continuous metric c: `records[k].metrics[c].reason ∈ {"model stale","model not built"}` (records only ⇒ works for TimesFM rows). Test: on `get_scenario('S1',1,n_ticks=900)` the cpu `no_model` ticks == union of `[t0,t0+dt)` (tick-end times) of cycles with `reason != built` from `on_cycle`, both restricted to `k+1 ≥` warm-up offset (exact).
- `L = post_gate_lookback_cycles × round(grid.dt_seconds/grid.tick_seconds)` = 12 ticks. A *decisive episode* = maximal run of consecutive ticks with `valid ∧ p_raw>δ`, `e0` = its first tick. Tick k of the episode is `injected-anomaly` if `¬quiet[k]` or `¬quiet[e0]`; else `post-gate` if `no_model[max(0,e0−L) … e0].any()`; else `fresh-model noise`. "Since the last scored tick" = scoring resumed after a no-model stretch ending ≤L ticks before onset; a tick-local rule would label only the first tick of each resumed run (S1 seed 1: the first run is 76 ticks long and starts 2 ticks after resumption), so the episode inherits. `fresh-model noise` is the residual class: on S7/S8 it contains reference misfit to multi-seasonal structure, NOT noise (say so in the note).
- Per-run `mechanism{lookback_ticks, counts{3 names}, runs[[k0,length,name]], sensitivity{"<L>": counts}}` (sensitivity at each `lookback_sensitivity_cycles`; counts sum == `classes.valid.decisive`, else `ValueError`). Real pods: `quiet`=all True, `no_model` from the pod records (`PodReal.mechanism`).
