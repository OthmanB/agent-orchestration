## Objective
Expand the Phase C matrix into resumable UNITS, run the TimesFM-3 forecasts at raw cadence (one call per production cycle) on the RTX PRO 4000 and store the raw quantiles `[C,V=4,260,9]` per unit as shards. ## Library contract (≤200 lines/module)
- `units.py`: frozen `Unit(kind, scenario|pod, seed|None, ctx_pts, mode)`; `unit_id(u) -> "syn:S1:1:11520:multi"`; `expand_units(cfg) -> list[Unit]` (118; order = slice order); `slice_units(cfg, name)`; `call_table(cfg) -> dict` (calls and B1-median wall per (V,N) — the table above must be reproduced exactly).
- `infer.py`: `forecast_contexts(forecaster, contexts: list[ndarray], horizon, batch) -> list[ndarray]` (chunking, sets `forecaster.config.per_core_batch_size = len(chunk)`, `return_quantiles=True`, never mixes V/N; output `(V,H,9)` or `(H,9)`); `batch_parity(forecaster, contexts, horizon, B)`.
- `runner.py`: `run_slice(cfg, slice_name, forecaster_call, *, device, hooks, max_minutes, own_pid)`: hygiene gate (B1 `snapshot/check`, `retry_wait_s`×`max_retries`) before the first unit and before every unit (`per_unit`); per unit: build series → C1 `plan_cycles` → `cycles_done(shard)` resume → contexts → `forecast_contexts` → shard flush every `flush_cycles` → manifest entry `{status, cycles, wall_s, ms_per_cycle, device, batch_effective, hygiene_snapshot, shard_sha256}`; an unknown-error unit is recorded `error` and the slice continues; the L0 probe stores `decisions.batch_cycles_effective` (=1 if the parity max rel > rtol) and later slices read it.
- `scripts/run_refcompare.py --config config/refcompare_run.yaml --device cpu|cuda --slice L1 [--smoke] [--dry-run] [--max-minutes N] [--out-dir D]`; `--dry-run` prints the unit/call/wall table without a model.
