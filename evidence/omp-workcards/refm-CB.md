## Design fixed by this card (D-S5 + R-candB corrections; verified on disk 2026-11-10)
K = emitted blocks of the fit window (`win_ts/win_val` in `_cycle`; steady K=570), T=300 s, `m0 = noise.min_fit_blocks` (48) = residual warm-up, `bin_i = phase_of(ts_i, …)`. For a finite width W (blocks):
- `d_i = mean(y[max(0,i−W):i])` (**exclusive**: blocks strictly older than i; NaN at i=0). `r_i = y_i − d_i`, accumulated **only for i ≥ m0** (vision's "shrinking head" is measurably destructive, R-candB §3.1). `S_i(j) = mean{r_s: m0≤s<i, bin_s=j} − mean{r_s: m0≤s<i}`; empty bin or no history ⇒ 0 (= legacy empty-bin rule). `F_i = d_i + S_i(bin_i)`, one-step residual `e_i = y_i − F_i` for i ≥ m0 (`adaptive_one_step_residuals`).
- Served model of a cycle = `AdaptiveStlState.fit(window, W)`: `level = mean(y[K−W:K])` (inclusive of the last fitted block — legal, it is `fit_end`), `S` from `r` over the whole window with the same W; `forecast(t1) = level + S[bin(t1)]`. Seasonal on the detrended residual; no joint estimation.
- **Record rule:** legacy steady R forecasts an entered block from the CURRENT window's earlier blocks (`stl_lite.py:303-322`: forget slid-out, then `advance_residuals`); cold = growing prefix. Both equal "the last `len(new_ts)` entries of the current-window vector `e`" (cold: `e[m0:]`; steady: the last m entries). Finite-W cycles append exactly those (width in force at entry, retained verbatim afterwards, as production retains residuals). Cold/steady geometry, `lo/hi`, log append-only: untouched.
- **Sentinel (= full window = today) is routed to the legacy path byte-for-byte:** the legacy F/R states run in EVERY cycle unchanged; a sentinel cycle serves `prior.F` and appends the legacy residuals. Its cv1 score uses `legacy_one_step_residuals` (prefix phase mean; empty bin ⇒ prefix mean). The adaptive formula at W=K is NOT identical to legacy (R-candB §3.1 claim corrected: `r` uses a moving `d`), hence the special case.
- **Selector (D-S5):** `criterion: cv1` = mean|e_i| over i ≥ m0 (same sample for every candidate and the sentinel; out-of-sample, leak-free); `criterion: ess` = `bartlett_ess(e[m0:], noise.bartlett_max_lag)/len` — the vision's objective, **diagnostic only, never default**, asserted degenerate (R-candB §4.1: smallest width in 18/18 windows). Scan ascending finite widths, then the sentinel; a challenger must be strictly better (ties → smaller width; sentinel only if strictly better). Candidates: log-spaced `round(geomspace(grid_min_minutes·60/T, grid_max_minutes·60/T, n_grid))`, unique, sorted, only those `< K`.
- **Degenerate ⇒ sentinel** (`Selection.reason`): `short_window` (K ≤ m0), `constant_window` (`ptp(y) ≤ constants.gauge_epsilon·max(1,|mean y|)` — **`constants.gauge_epsilon` EXISTS** at `reference.yaml:76` / `config.py:Constants` (1e-9, parity-checked literal): R-candB CONTRADICTION-8 is wrong for the lab; reuse it, add NO key), `no_candidates`, `nonfinite`. Guard: the ESS gate runs on raw blocks before any hook ⇒ gated set, `fit_end`, `model_t0`, `ess` identical A vs B (asserted, not hoped).
- YAML (`reference.yaml`, additive; every key provenance-commented "lab-only study key, no production counterpart; vision §3.1 `span.method gradient`/`fallback` not ported — grid only, fallback is structural"): `baseline.continuous.trend: {method: boxcar}` (+ the adaptive `span` block shown as a COMMENT).
