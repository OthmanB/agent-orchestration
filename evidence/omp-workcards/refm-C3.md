## Decisions (P)
- **D-1 Offset (model-independent tick set V0)**: `offset = first_valid_tick(576 blocks, origin)` = **1118** for synthetic scenarios (from YAML via C1; asserted equal to the measured `first_valid_k_plus_1` of every 2 d TimesFM unit — a TimesFM property, NOT an STL/gate property); a real pod's offset is its own TimesFM first scored tick (1118…1123, C1 D-6). `V0 = {k : k+1 ≥ offset}` is applied to ALL references via `hcfg_common`. STL's Markov posterior has run since tick 584 while TimesFM's starts near 1116, but the quiet fixed point is reached in ≈100 ticks and the first onset is ≥1332, so the first 214 valid ticks absorb the transient (E checks p_raw at 1118–1220 in the FLAT rows). Part-1 numbers (5 seeds, offset 584) appear only as a labelled column when `part1-profile.json` exists.
- **D-2 Rows**: per scenario `stl-gate-on`, `stl-gate-off`, `tfm-uni-2d`, `tfm-multi-2d` (seeds 1–3, `aggregate_seeds`) [+ optional `candB-gate-on`, `candB-gate-off`, D-7]; sweep rows `tfm-{uni,multi}-{1d,1h}` seed 1 only (labelled single-seed); deltas of each tfm row (and each candB row) vs BOTH stl rows: latency to leave decisive-normal and latency to decisive-anomaly (ticks, per event), undecided-band occupancy and decisive-anomaly occupancy (absolute), settle (ticks), fidelity MAE ratio per signal, availability. Every row also carries `classes` (valid and quiet), p_raw quantiles q05…q99/max and the `mechanism` counts of ticks >0.8 (`injected-anomaly`/`post-gate`/`fresh-model noise`; tfm rows have no gate, so `post-gate` is expected 0).
- **D-3 Masking probe** (units `leak:S4@x`/`S6@x`, `x∈{cpu,mem,rx_bytes,none}`, seed 1, ctx 11520, multi; `rx_bytes` also bumps tx, C1 variants). For burst signal A and CLEAN signal B (A=cpu: B∈{mem, rx_bytes, tx_bytes}; A=mem: B∈{cpu, rx_bytes, tx_bytes}; A=rx_bytes: B∈{cpu, mem}; tx_bytes is evaluated as a clean B wherever it is not burst), paired noise (C1 fact 6): `dF_B[c] = mean_{b=6..11}(F_B^{S@A}[c,b] − F_B^{S@none}[c,b]) / σ_B` (`σ_B` = `noise_sd` of the `SignalCfg` in `hcfg.scn.signals` whose `short == B`), over the cycles whose context contains burst blocks (a burst can reach a forecast only through the context, i.e. for ≤2 d after it, never before). Report `max|dF_B|`, mean|dF_B|, own effect `dF_A` as scale, ratio `max|dF_B|/max|dF_A|`, B's strike count (`p<α_strike`) and residual mean/sd in `[onset, onset+576)` for `S@A` vs `S@none`. Uni side: assert the B-contexts of `S@A` and `S@none` are `array_equal` (⇒ uni leakage ≡ 0.0 by construction, no GPU units). Also S4 (all signals burst at once) vs `S4@x`: per-event difference of the latency to leave decisive-normal and of the latency to decisive-anomaly (joint-burst masking).
- **D-4 Flat (D-A iv)**: (a) synthetic FLAT, seeds 1–3, K=11: `p_raw` {q50, q99, max, frac_normal (<0.2), frac_undecided, frac_decisive (>0.8), `n_decisive`, secondary `frac_lt_calm_p` (<0.02)} for stl-gate-on/stl-gate-off/uni/multi [+ candB] at the common offset; (b) real flat = 10 pods, K=11 chain, the SAME 6.0 d slice (`real_slice`) for all four references; per pod and fleet the same summary + fidelity MAE per continuous metric. Verdict (thresholds from YAML `flat{calm_p 0.02, threshold 0.2, max_outside_fraction 0.02}` + the harness `scoring.decisive_threshold` 0.8; not chain laws): `calm` = frac_normal ≥ 1 − `max_outside_fraction` (≥98 % of valid ticks decisively normal); `marginal` = not calm and `n_decisive` == 0; else `fails`; `n_decisive` and the max are ALWAYS reported beside the verdict (a calm row may still hold >0.8 ticks); both `stl` verdicts beside it; (a) and (b) are reported side by side (synthetic is the yardstick, real the confirmation).
- **D-5 Special rows**: S3 per pulse (E1 pre-switch, E2 after ×3 noise): latency to leave decisive-normal, latency to decisive-anomaly and peak `p_raw` in `[onset, onset+8]` for all four references (identical anomaly, widened noise); S5: scored-tick fraction and rx fidelity after gaps (the model sees the rx gap as NaN filled by its own interpolation, C1 D-2; the chain skips the uncomputable rx blocks exactly as for STL, so the measured effect is the forecast quality just after each gap); S7/S8: MAE ratio per signal + undecided-band and decisive-anomaly occupancy (advantage reported, not gated: `MAE_tfm<MAE_stl` on ≥3 of 4 signals, per stl row).
- **D-6 ESS gate and tick set (D14)**: the floor is read from `reference.yaml`, never retyped. `stl-gate-on` = as deployed (the Part-1 yardstick); `stl-gate-off` = `dataclasses.replace(cfg, noise=dataclasses.replace(cfg.noise, min_effective_samples=0))` on the lab `RefConfig` (analysis-only; `reference.yaml` untouched). Every table shows both STL rows and every 'TimesFM better/worse than STL-lite' sentence names which one (the gate effect and the model effect are different findings; S1 is dominated by the gate). **Tick sets**: primary = each reference on its OWN scored ticks inside V0 — never intersected with the gate's scored set, so the gate cannot dictate the set; each row carries `availability = |scored ∧ V0|/|V0|`, `n`, and `stale_ticks` (ticks ≥ first model with no model). Secondary `matched` = intersection of all four references' valid ticks (`n_matched` reported; occupancy + fidelity columns only; `not_available` below `matched.min_ticks`); it separates gate from model. Gate evidence per scenario/seed/metric: STL `ess_gated_cycles/cycles` and ESS min/median (from `StlLiteProvider.run(on_cycle=…)` on the pod's blocks), TimesFM `ess_would_gate_fraction` (share of served cycles with informational `ess < floor` = windows the deployed gate rejects and TimesFM still serves); seeds 1–3 gated-cycle counts must equal `part1-profile.json`'s `ess` block when present (mismatch ⇒ report, never edit).
