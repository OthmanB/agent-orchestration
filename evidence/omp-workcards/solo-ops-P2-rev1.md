## Fixes (symbols; code is E's)

1. **[blocker] decision threshold shape** — `soloRenderTimeline` must call `soloDecisionFromProbability` with the raw `{normal, anomaly}` shape (`thresholdsRaw`), not the renamed `{normal_threshold, anomaly_threshold}` object that is only for `renderTimeseries`. Keep `p ≥ anomaly → anomaly`, `p ≤ normal → normal`, else `undecided`; null/undefined/non-finite `p` → `undecided`; missing/null/non-finite thresholds or `normal ≥ anomaly` → `unknown`. Guard against `Number(null) === 0` for the thresholds in the helper (null/undefined/'' ⇒ invalid) AND for the threshold lines drawn by `renderTimeseries` (a null threshold must not draw a line at 0).
2. **Empty-state placeholder** — the successful render path of `renderTimeseries` must remove the "No timeseries data available" placeholder paragraph that `renderTimeseriesMessage` leaves (remove only that owned node; do NOT wipe the Plotly DOM on ordinary refreshes). Both transitions must hold: empty→populated (no paragraph in DOM/innerText) and populated→empty (message shown, counter 0).
3. **Null probability = gap** — in `renderTimeseries`, a null/undefined probability must stay `null` (Plotly gap), never `Number(null) = 0`. Only finite numbers plot. Counter semantics unchanged (count of points with renderable timestamp).
4. **Null residuals** — reject null/undefined BEFORE `Number(...)`: `soloCdfAt(points, x)` with x null/undefined → `null`; CDF `points` entries with null coordinates are skipped in lookup/interpolation; a `latest_recorded_residual` whose `residual` is null/non-finite → no marker, no PDF vertical line, annotation `F(r) n/a`; PDF samples `[ts, residual]` with a null/undefined/non-finite residual are excluded (never coerced to 0).
5. **Timestamp validity** — in `renderTimeseries` filtering (shared) and in `soloRenderTimeline`, a point counts/plots only if its time parses to a valid Date (`Number.isFinite(date.getTime())`); null/missing epoch rejected before coercion; out-of-range finite epochs (e.g. 1e20) are skipped, never throw. The counter returns the number of actually plotted points.
6. **Prose (item 6)** — the Pod-Level panel paragraph (`index.html` ~line 972, currently "amber ticks are published raw (calibrating)") must use the workcard's neutral terms: raw = published without a calibrated mapper (no healthy calibrated mapper), not "calibrating". Keep the marker-colour and gate-cross explanations. Also grep the Guide pages for any other "calibrating" wording equating raw with calibration-in-progress and fix it the same way.
7. **Guide CDF wording** — the Residual PDF/CDF Guide page (~line 1159) must not describe `F(r)` as "the share of persisted residuals at or below r". Describe it only as the empirical mid-rank CDF of the persisted residuals (strictly inside (0,1)), y-axis `F(r)`; PDF y = density of the same residuals. No closed-form count formula.
8. **One time convention across solo panels** — the timeline must place a tick at the same displayed clock time as the other solo time charts (which feed epoch-ms numbers). For the solo path pass epoch-ms numbers as `t` (not ISO strings) and make `renderTimeseries` robust to that: its layout `xaxis` must explicitly set `type:'date'` (title 'Time' kept) so a numeric x is not auto-inferred as linear; its sort/validity code must accept both ISO strings (external path, unchanged contract) and epoch-ms numbers. External-path rendering must remain identical for ISO inputs.
