## Library contract (signatures; loguru, type hints, `from __future__ import annotations`; stdlib `urllib/gzip/csv/hashlib`, numpy — no new deps)
- `greptime.py`: `class GreptimeError(RuntimeError)`; `GreptimeClient(endpoint, db, timeout_s).query(sql) -> list[dict]` = one GET `?db=&sql=`, parse `output[0].records` (`schema.column_schemas[*].name` + `rows`, ts = epoch ms); non-2xx / `error` body / URLError / `len(rows) != total_rows` → `GreptimeError` (message keeps the server text).
- `package.py`: `load_settings(path) -> Settings` (frozen dataclasses; paths resolved against `path.parent.parent`); `sql_ts(epoch_ms) -> 'YYYY-MM-DD HH:MM:SS.mmm'` (UTC); `series_sql(...)`/`count_sql(...)` (the §2.4 text; count = `SELECT pod, count(*) AS n … GROUP BY pod`); `fetch_series(client, settings, metric, pod, t0_ms, t1_ms) -> Series(ts_ms int64, value float64, container, name)`; `validate_series(series, settings, t0_ms, t1_ms) -> dict` raising `ValueError` naming pod/metric/check for: rows outside `rows_per_hour × window_hours`; ts not strictly increasing; any `dt < min_dt_s` or `>= max_dt_s`; `n_name != 1` or `n_container != 1`; non-finite value; ts outside window or first/last sample farther than `edge_slack_s` from the bounds (proves UTC interpretation); returns stats (rows, min/max ts, min/mean/max dt, n_name, n_container, `n_dt_gt_counter_max_gap`, rows per flag window); `write_series(series, path) -> {sha256, size_bytes}` (CSV `ts_epoch_ms,value,container,name`, value via `repr(float)`, gzip `mtime=0` ⇒ byte-deterministic, tmp file + `os.replace`); `build_manifest(...)`.
- `oracle.py`: `fetch_oracle(settings, pod_name) -> bytes` (GET 200 or error); `check_oracle(payload, settings) -> dict` (`len(history)==288`, every `tick_epoch % 300 == 0`, strictly +300, the 4 continuous metrics present under `details.metrics`); `block_value(ts_s, value, tick, law, max_gap) -> BlockValue | None` (§5 laws; `None` = invalid/empty); `spot_check(...)` (`random.Random(seed)`; per pod, `ticks_per_pod` ticks eligible for all 4 continuous metrics (counter metrics: `block_attribution.reason == "emitted"`), compare to `details.metrics[m].observed` with `rel_tol`; for `mem` ALSO compute the counter-law value and report both + `block_attribution is None` count).
- `loader.py` (**the API**): `load_flat_series(pod_suffix: str, metric_short: str, *, root: Path | None = None) -> tuple[np.ndarray, np.ndarray]` = `(ts_s, value)`, both float64, `ts_s = ts_epoch_ms/1000` (epoch seconds), strictly increasing, raw units; resolves file via the manifest (`root` = study dir, default derived from `__file__`), verifies sha256 vs manifest (`ValueError` on mismatch; unknown pod/metric → `KeyError` listing valid ones); also `list_pods(root=None) -> list[str]` (suffixes, YAML order), `list_metrics(root=None) -> list[str]`, `pod_full_name(suffix, root=None) -> str`, `load_oracle(pod_suffix, root=None) -> dict`, `load_p3_ticks(root=None) -> list[dict]`, `read_series_file(path) -> (ts_s, value)`.
- Manifest keys: `schema_version, created_utc, window{start_utc,end_utc,start_epoch_ms,end_epoch_ms,hours,warmup_rows_skipped}, source{…,sql_template}, pods[{suffix,group,name}], metrics[{short,table,container,kind}], files[{pod_suffix,metric_short,path(rel. data/raw),rows,sha256,size_bytes,min_ts_ms,max_ts_ms,min_dt_s,mean_dt_s,max_dt_s,n_container,n_name,name_id,n_dt_gt_counter_max_gap,greptime_count,flag_rows}], greptime_tables{table:{min_ts_ms,max_ts_ms}} (`SELECT MIN/MAX(greptime_timestamp)` only, no table COUNT), oracle{fetched_utc,files[{pod_suffix,path,sha256,size_bytes,history_len,tick_first,tick_last}],spot_check{…}}, p3{path,sha256,rows,source_sha256}, solo_mode_config{window,undersampling,validity,degraded,metrics(names)}, flags[], validation{hard_checks_passed,thresholds}`. Script hard-fails if the YAML metric list (table, kind, container) differs from the snapshot's `solo_mode.metrics`.
- `scripts/package_flat_load.py --config config/data_packaging.yaml [--end-utc ISO]`: one run = oracle → raw (validate each file right after fetch) → grouped-count cross-check (every file rows == `greptime_count`) → Greptime table min/max → P3 copy (`.jsonl.gz`, line count) → spot-check → manifest written LAST and only if everything passed; any failure → non-zero exit, no manifest.
