## Decisions (P)
- **S AMENDMENT (binding, supersedes the 'staircase by construction' clause below): within-block dither.** A piecewise-constant 5-min staircase is NOT a valid raw-cadence input for Phase C (Part 2 §3: the candidate must see raw samples, not box-cars). Add YAML `sampling.within_block{mode: dither|staircase, half_width: 0.3}` and make `dither` the default. Dither is **mean-preserving per block on the regular grid**: counter increments `x_b·g/unit·(1+η_k)`, gauge samples `x_b·(1+η_k)`, with `η_k ~ U(−a,a)` drawn from its own spawned RNG stream, then `η` re-centred so the mean of η over each block's 20 samples is exactly 0 (validate `2·half_width < 1`, so values stay positive). Consequence to TEST: on the regular grid `build_blocks(encode_raw(x)).value == x` still holds (rel 1e-9) in BOTH modes, so Part 1 chain results are independent of the raw encoding; `staircase` is kept only for a unit-test sensitivity; the raw series differ across the two modes and the dithered raw has non-zero within-block variance (assert it). Document in `markdown/scenarios.md`. Jitter mode: dither applies too (exactness not claimed).
- Noise = production dialect (`noise.kind: factor_ar1`, φ .5, weights [.1,.7,.2], `groups [[0,1,2]]` ⇒ cross-signal corr 0.8) because the Part 1 spec says "extend the fixture harness" and R-A1 §7's flat expectation was observed with it; `noise.kind: white` is also implemented (generate.py dialect; A1c runs it as a sensitivity). Noise is block-level (one draw per block); raw within a block is dithered (see S AMENDMENT), so Phase C's raw-cadence input is not a degenerate staircase.
- **Unit bridge**: block-native value `x`; counter increment over a gap `g` = `x·g/counter_unit_interval_seconds` (15), gauge sample = `x`; regular grid ⇒ block value == `x` exactly; jitter (mean gap 16) ⇒ block ≈ `x·16/15`. Labels "CPU %/MiB/MB/s" are display only.
- S1 sawtooth on cpu AND memory (vision text, C4); S2 drift HOLDS (monotone level drift; `end=None`); S3 anomalies are 6-block pulses (a 1-block spike cannot reach p_raw>0.2, [INFERENCE] R-A1 §6); S5 gap = 30 min every 2 h on rx; S7 = daily + 6 h + 7 h (non-divisor, learnable inside a 2-day context — a weekly period is unlearnable by ANY ≤2-day reference and the series is <1 cycle; the generator accepts any `period_seconds`); S8 = daily + 3 h dominant + 2.5 h non-divisor twin. Main may overrule by editing YAML only.

## Library contract (type hints, `from __future__ import annotations`, loguru, numpy only, ruff-clean; each module ≤ 200 lines)
- `config.py`: frozen `ScenariosConfig`; `load_scenarios_config(path, ref_cfg) -> ScenariosConfig` (validates shorts vs `ref_cfg.metrics.entries`, `T/cadence` integer, groups partition, event/gap inside the timeline, gap edges multiples of `T`).
- `noise.py`: `ar1_unit(rng, n, phi)`; `latent_noise(seed, n, noise_cfg, k) -> (k, n)` (spawn order fixed and documented: common, group₀…, eps₀…, jitter; prefix stable under `n`). `components.py`: `component_values(spec, t_block_start)`, `event_effect(...)`, `noise_scale(...)`.
- `raw.py`: `encode_raw(targets: Mapping[name, ndarray(n)], *, counter: Mapping[name,bool], origin, T, sampling, jitter_rng=None, gaps=()) -> dict[name, (ts_s, value)]` — regular: `ts=o+cadence·k`, `k=0..n·T/cadence` (n·20+1 samples); counters cumulative from `counter_initial_value` with increments `x_b·gap/unit`; gauge `x_b`; sample→block by the block law's own attribution (counter `ceil((ts−o)/T)−1`, gauge `floor`, samples beyond block n−1 reuse block n−1); jitter: `ts_{k+1}=ts_k+mean_gap+U(−hw,hw)` ms-rounded until `ts ≥ o+nT+mean_gap`; `GapSpan` removes samples with `t_start<ts<t_end` of one signal ⇒ on the regular grid (both ends kept) exactly `(t_end−t_start)/T` uncomputable blocks (`empty…`, last `bad_gap`; verified with `build_blocks` at planning: 78 gaps ⇒ 390 `empty` + 78 `bad_gap`); under jitter no sample sits on the edges, so the first block AFTER each gap also turns `bad_gap` (`GapSpan.blocks` is the regular-grid set). Raises `ValueError` on negative target (counters must stay monotone — no clipping).
- `truth.py`: frozen `Event{id, kind, role 'anomaly'|'regime', signals, onset, end (exclusive; None = persists), params}`, `GapSpan{signal, t_start, t_end, blocks}`, `GroundTruth{scenario, seed, n_ticks, display_start, events, gaps, params}` with `anomaly_events()` and `quiet_mask(margin_after, margin_before=0) -> bool[n]` (False on `[onset−before, (end or n)+after)` of anomaly events only; regimes and gaps stay quiet).
- `registry.py`: frozen `Scenario{name, seed, origin, n_ticks, display_start, signals (shorts), names {short→canonical}, raw, target, clean (noise-free part), truth}` + `blocks(ref_cfg) -> dict[canonical, BlockSeries]` (calls `build_blocks(..., agg="mean", origin=origin, n_blocks=n_ticks, counter=is_counter_metric(name, kind))`); `get_scenario(name, seed, *, n_ticks=None, sampling_mode=None, noise_kind=None, scn_cfg=None, ref_cfg=None)` (None ⇒ load `config/*.yaml` relative to the study dir; unknown name → `KeyError` listing names; `n_ticks ≤ display_ticks` → `ValueError`); `list_scenarios()` in YAML order.
- `scenarios/__init__.py` exports exactly: `Scenario, GroundTruth, Event, GapSpan, ScenariosConfig, load_scenarios_config, get_scenario, list_scenarios, encode_raw` (A1c imports these; `encode_raw`'s `sampling` argument is `ScenariosConfig.sampling`).
