## Library contract (signatures only; keep modules small, loguru, type hints, `from __future__ import annotations`)
- `config.py`: frozen `Settings`/`ModelSpec`/`CostSpec`; `load_settings(path) -> Settings` (paths resolved against `path.parent.parent`); `CostSpec.param_count` = `model.param_count` (one source).
- `checkpoint.py`: `sha256_file`; `read_safetensors_header(path)` (8-byte LE length + JSON; params = Σ∏shape; no torch); `verify_checkpoint(model) -> dict` (files, size, sha256, param count; `ValueError` on mismatch); `build_manifest(settings) -> dict` (repo_id, revision, file, sha256, size_bytes, param_count, dtypes, licence_name, code_licence, `weights_committed: false`, versions of timesfm/torch/numpy/python/huggingface_hub/safetensors via `importlib.metadata` — `"not installed"` if absent — platform, UTC time).
- `loader.py`: `configure_hf_home(settings)` (sets `HF_HOME` **before** any `huggingface_hub`/`timesfm3` import; scripts call it first); `load_forecaster(settings, device)`: backend from `runtime.devices`, torch → `torch.set_num_threads(cpu_threads)` + `from_pretrained(str(local_dir), device=device, local_files_only=True)`, mlx → `from_pretrained(str(local_dir), local_files_only=True)`, unknown device → `ValueError`; torch/timesfm3 imported lazily.
- `forecast.py`: `Forecast(median, quantiles)`; `ForecastWrapper(forecaster, settings).forecast_univariate(series (T,), horizon)` / `.forecast_multivariate(series (V,T), horizon)`: `ValueError` on wrong ndim, `T<1`, `V>max_variates`; call `predict(series.astype(float32), horizon=horizon, return_quantiles=True)`; verify output shapes; `median = quantiles[..., median_index]` (never `out.forecast`).
- `flops.py`: `horizon_patches(horizon, cost)`, `forecast_flops(n_context, n_variates, horizon, cost) -> float` (clips N at `max_context`; `ValueError` for N<1, V<1, V>max_variates, H<1); docstring states law + convention.
- `smoke.py`: `make_signal(n_variates, n, signal_cfg)` and one function per check, each in a guard returning `{status: ok|fail|observed|error}` (`error` keeps `type`, `str(exc)`, last 15 traceback lines; later checks still run):
  - `shapes`: V=1 and V=3 at `small_context`; documented shapes, finite, quantiles ascending, median == `quantiles[...,4]`.
  - `determinism`: V=3 twice; `max_abs_diff <= determinism_atol`.
  - `flat`: V=1 on `values[0]`, V=3 on all; per variate max-abs `median − value`, max quantile spread, finite flag, `collapses_to_mean` (`max|delta| <= collapse_rel_tol·max(|v|,1)`); status `observed` (never fails on the value).
  - `truncation`: `long_context` forecast vs forecast of its last `max_context` points; `max_abs_diff <= atol`.
  - `latency`: cells ascending by `n·v`; `warmup` calls then `runs` timed calls (`perf_counter` around the wrapper) → `median_ms,min_ms,max_ms,gflop,gflops_per_s,rss_hwm_mb` (`ru_maxrss`: bytes on darwin, KiB on linux; a process **high-water mark**, hence the order), `mps_allocated_mb` (`torch.mps.current_allocated_memory()`) only for device=mps.
  - `parity` (device≠cpu only): load a second CPU forecaster; per `parity.cases` → `max_abs_diff_quantiles`, `max_abs_diff_median`, input `ptp`; on cpu `parity: null`.
  - JSON root: `schema_version, device, backend, load_seconds, rss_after_load_mb, torch_threads, os_cpu_count, versions, checks, parity, overall` (`ok` iff shapes/determinism/truncation/latency are `ok`).
- `scripts/fetch_timesfm3.py --config config/timesfm3.yaml [--verify-only]`: `configure_hf_home`; `huggingface_hub.snapshot_download(repo_id, revision, allow_patterns, local_dir)` (skipped by `--verify-only`); `verify_checkpoint`; write the manifest (indent 2, sorted keys); exit ≠0 on mismatch.
- `scripts/smoke_timesfm3.py --config … --device cpu|mps|mlx`: configure, load, run checks, write `outputs.smoke`; **always writes the JSON, even on load failure** (`overall:"error"`, exception verbatim); exit 0 iff `overall=="ok"`.
